# Inclusive Assessment Design in K-12 Classrooms - Module Content

## Module Overview
- **Duration**: 20-30 minutes
- **Target Audience**: K-12 educators
- **Learning Objectives**:
  1. Identify barriers to assessment accessibility and fairness
  2. Apply UDL principles to assessment design
  3. Modify assessments to support diverse learner needs

## Slide Structure

### Slide 1: Title Page
- Title: "Inclusive Assessment Design in K-12 Classrooms"
- Subtitle: "Creating equitable and accessible assessments for diverse learners"
- Author: [Your Name]
- Course: D299
- Hero image: Diverse classroom with inclusive practices

### Slide 2: Module Overview
- Learning Objectives (3 main points)
- Estimated Completion Time: 20-30 minutes
- Materials Needed: Device with internet access

### Slide 3: Why Inclusive Assessment Matters
- Key point: Traditional assessments may create unintentional barriers
- Benefits of inclusive assessment design:
  - Improves accessibility
  - Supports equity
  - Increases engagement
  - Allows multiple ways to demonstrate learning
- Multimedia: Short video on inclusive education/UDL

### Slide 4: Common Assessment Barriers
- 4 barrier cards:
  1. Language Barriers (complex wording)
  2. Accessibility Barriers (small text, poor contrast, no captions)
  3. Cultural Bias (examples that exclude learner experiences)
  4. Single Response Method (only essays/tests allowed)

### Slide 5: Formative Assessment #1 - "Spot the Barrier"
- Activity: Identify at least 2 barriers in a sample assessment
- Image: Poorly designed assessment (tiny text, too much reading, no visuals, timed only)
- Interactive element: Clickable answer boxes or text reflection
- Feedback provided after submission

### Slide 6: Introduction to UDL
- Title: "Universal Design for Learning (UDL)"
- Definition: UDL helps teachers design flexible learning experiences
- 3 UDL Principles:
  1. Multiple Means of Engagement (Why)
  2. Multiple Means of Representation (What)
  3. Multiple Means of Action & Expression (How)
- Visual: UDL 3.0 wheel diagram

### Slide 7: Applying UDL to Assessment Design
- 3-column layout:
  - **Engagement**: Student choice, relevant topics
  - **Representation**: Visuals, audio supports, captions
  - **Action & Expression**: Presentations, videos, written responses

### Slide 8: Formative Assessment #2 - "Knowledge Check"
- Multiple choice questions (3-4 questions):
  1. Which is an example of multiple means of representation?
  2. Which assessment barrier affects accessibility?
  3. Which strategy supports learner choice?
- Interactive buttons with immediate feedback
- Correct/incorrect response pages

### Slide 9: Accessibility Best Practices
- Key practices:
  - Readable fonts
  - High color contrast
  - Captions/transcripts
  - Alt text
  - Chunked information
  - Flexible formats
- Visual: Before-and-after comparison

### Slide 10: Case Study Application - "Classroom Scenario"
- Scenario: "A 7th-grade teacher gives students a timed written essay with no visuals, no accommodations, and complex directions."
- Prompt: "How could this assessment be redesigned to be more inclusive?"
- Interactive element: Reflection textbox or clickable ideas

### Slide 11: Formative Assessment #3 - "Inclusive Assessment Checklist"
- Self-reflection activity
- Interactive checkboxes for inclusive practices:
  - ☑ Flexible response options
  - ☑ Visual supports
  - ☑ Captions/transcripts
  - ☑ Clear instructions
  - ☑ Student choice
- Learners identify which they use and which they want to implement

### Slide 12: Summative Assessment
- Task: "Redesign a traditional classroom assessment using at least 3 inclusive assessment strategies learned in this module."
- Requirements:
  1. Reduce barriers
  2. Apply UDL principles
  3. Provide flexible learner supports
- Submission options (demonstrating UDL):
  - Type responses
  - Record audio
  - Create a visual plan

### Slide 13: Module Summary - "Key Takeaways"
- Inclusive assessments:
  - Improve equity
  - Reduce barriers
  - Support diverse learners
  - Increase student success
- Effective inclusive design includes:
  - Accessibility
  - Flexibility
  - Multiple ways to demonstrate learning

## Assessment Components

### Formative Assessment #1: Spot the Barrier (Slide 5)
- **Type**: Image-based identification activity
- **Objective**: Identify accessibility and design barriers in assessments
- **Interaction**: Click on barriers or type responses
- **Feedback**: Provides list of possible barriers with explanations

### Formative Assessment #2: Knowledge Check (Slide 8)
- **Type**: Multiple choice quiz
- **Objective**: Test understanding of UDL principles and assessment barriers
- **Questions**: 3-4 questions with immediate feedback
- **Interaction**: Click answer buttons, receive correct/incorrect feedback

### Formative Assessment #3: Inclusive Assessment Checklist (Slide 11)
- **Type**: Self-reflection checklist
- **Objective**: Identify current practices and areas for growth
- **Interaction**: Check/uncheck practices, optional reflection
- **Feedback**: Encouragement to implement new strategies

### Summative Assessment (Slide 12)
- **Type**: Authentic task with multiple submission formats
- **Objective**: Apply all learned concepts to redesign an assessment
- **Requirements**: 
  - Identify original assessment barriers
  - Apply at least 3 inclusive strategies
  - Explain how UDL principles are addressed
- **Submission Options**: Text, audio, or visual format (demonstrating UDL)

## Design Standards
- **Font**: Aptos, Open Sans, or Montserrat
- **Background**: White/light neutral
- **Accent Colors**: Dark blue + muted green
- **Typography**: Large headings, minimal text per slide
- **Visuals**: Icons and visuals on every slide
- **Accessibility**: High color contrast, alt text, captions, no color-only meaning, chunked text, consistent layouts
